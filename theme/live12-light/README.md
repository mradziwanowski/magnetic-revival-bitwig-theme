# Live 12 Light

A light grey Bitwig Studio palette in the style of Ableton Live 12, for Patchbay's **Framework: Themes**.

Colours only. For the full look (flat knobs with cyan value arcs, flat device headers, readable text and icons on every surface, Live-style device panels) also enable the Live 12 Skin mods: Widgets, Ink Guard and Device Panel Styles.
